复用 stack 主题的配置

我们可以把 Stack 主题的示例配置直接复制过来，同时可以打开本地地址体会一下 Hugo 近实时渲染的魅力。

1

cp ./themes/hugo-theme-stack/exampleSite/hugo.yaml hugo.yaml

把 stack 主题的 content 目录下除post/richcontent的所有内容都复制到 /src/content

1
2

/src # cd themes/hugo-theme-stack/exampleSite/content/
/src/themes/hugo-theme-stack/exampleSite/content # find . -path ./post/rich-content -prune -o -print0 | cpio -pdmv0 /src/content/

如果richcontent也复制过来，渲染会报如下错误

Docker Compose配置如下

点击查看 docker-compose 配置
``` yaml
services:
  hugo:
    image: hugomods/hugo:exts
    container_name: hugo
    hostname: hugo
    restart: unless-stopped
    command: server -D
    # restart: no
    # command: new site /src --format yaml # format支持json yaml toml
    ports:
      - "18099:1313"
    volumes:
      - "/mnt/user/appdata/hugo/progressio:/src"  # progressio是项目目录，/src是Hugo默认工作目录
      - "/mnt/user/appdata/hugo/cache:/tmp/hugo_cache"
    networks:
      - hugo
    environment:
      - PUID=99
      - PGID=100
      - UMASK=000
      - TZ=Asia/Shanghai
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:1313"]
      interval: 30s
      timeout: 5s
      retries: 3
    logging:
      driver: json-file
      options:
        max-size: 100m

  twikoo:
    image: imaegoo/twikoo
    container_name: twikoo
    hostname: twikoo
    restart: unless-stopped
    ports:
      - "31080:8080"
    volumes:
      - "/mnt/user/appdata/twikoo/data:/app/data"
    networks:
      - hugo
    environment:
      - PUID=99
      - PGID=100
      - UMASK=000
      - TZ=Asia/Shanghai
      - TWIKOO_THROTTLE=1000
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:31080"]
      interval: 30s
      timeout: 5s
      retries: 3
    logging:
      driver: json-file
      options:
        max-size: 100m

networks:
  hugo:
    name: hugo
    driver: bridge
```

部署、配置完成后，打开任意一个文章，在页面的最下方就能看到评论区了。
