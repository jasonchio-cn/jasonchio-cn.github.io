MIoT Spec

概念及作用

MIoT Spec 是MIoT Specification 的缩写，是对于 IoT 设备规范化的功能性描述，是米家平台制订的物联网协议。其包含如下定义：

  • 功能定义；
  • 交互模型；

通过统一的 Spec 协议接入，设备得以实现与云端、插件的通信、平台消息推送、自动化联动等通用能力。

Spring AI

框架定位

The Spring AI project aims to streamline the development of applications that incorporate artificial intelligence functionality without unnecessary complexity.

The project was founded with the belief that the next wave of Generative AI applications will not be only for Python developers but will be ubiquitous across many programming languages.

Spring AI框架是一个各大模型的接入框架，对各模型的接入进行抽象封装，屏蔽底层细节，以快速完成对大模型的集成。

要求：

  • JDK 17+;
  • SpringBoot 3.x

发布时间线

Spring AI 目前处于快速迭代开发的阶段，但1.0.0-SNAPSHOT版本的发布，说明其架构设计基本成型。

主要Feature

  • 支持目前主流大语言模型平台；
    • 通义千问：“我非主流？！”
  • 支持众多模型类型；
    • 聊天、文生图、语音转文字、文字转语音等；
  • 支持主流的向量数据库或平台；
    • ElasticSearch、PostgreSQL、Redis、Neo4j等；
  • 支持函数调用；
    • 取决于模型是否支持，OpenAI、Gemini等
  • 用于数据工程的ETL框架；
    • 数据抽取、转换、加载；
    • 在实现RAG应用时，需要将外部的文档、PDF、PPT、DOC、图片作为大模型回答上下文；

    @Autowired  
    @Qualifier("tongYiSimpleServiceImpl")  
    private TongYiService tongYiSimpleService;  
  
    @GetMapping("/example")  
    public String completion(  
          @RequestParam(value = "message", defaultValue = "Tell me a joke")  
          String message  
    ) {  
  
       return tongYiSimpleService.completion(message);  
    }

	@GetMapping("/stream")  
	public Map<String, String> streamCompletion(  
	       @RequestParam(value = "message", defaultValue = "请告诉我西红柿炖牛腩怎么做？")  
	       String message  
	) {  
	  
	    return tongYiSimpleService.streamCompletion(message);  
	}
}
