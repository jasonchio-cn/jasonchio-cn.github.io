背景

博主有一个无用的 U 盘想将其挂载到基于 Ubuntu Server 20.04 LTS 的树莓派 4B 中拓展存储。为了方便 PC 和树莓派两个平台都可以读写，所以格式化为 NTFS 格式（exFAT 格式也可以），并在树莓派中设置成开机自动挂载，方便使用。

开机自动挂载方法

Ubuntu Server 20.04 LTS 默认就可以挂载 NTFS 格式的设备（至少在博主的设备上可以），无需安装其他软件。

输入 sudo blkid /dev/sda1

可以看到格式为 ntfs，记录下 UUID 的值

修改 fstab

输入 sudo vim /etc/fstab

1
2

LABEL=writable  /        ext4	defaults        0	1
LABEL=system-boot       /boot/firmware	vfat    defaults        0       1

按照这个格式添加自己的设备即可

格式：<fs spec>	<fs file>	<fs vfstype>	<fs mntops>	<fs freq>	<fs passno>

<fs spec>：分区定位，可以给UUID或LABEL，例如：UUID=20466764466739A4 或 LABEL=storage
<fs file>：具体挂载点的位置，例如：/home/ubunutu/storage
<fs vfstype>：挂载磁盘类型，根据实际情况填写，linux 分区一般为 ext4，windows 分区一般为 ntfs
<fs mntops>：挂载参数，一般为defaults
<fs freq>：磁盘检查，默认为0，需要开机检查磁盘则为1
<fs passno>：引导选项，0不启动，1启动，2非启动，一般情况下只能为0或2

每一个选项之间，使用 Tab 而不是空格。

所以可以增加一条配置

1
2
3

UUID=20466764466739A4   /home/ubunutu/storage   ntfs    defaults        0       2
# 或者
LABEL=storage	/home/ubunutu/storage   ntfs    defaults        0       2

重启查看一下是否自动挂载到了指定位置。
