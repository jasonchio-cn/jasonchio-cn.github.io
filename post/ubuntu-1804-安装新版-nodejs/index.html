Ubuntu 18.04 安装新版 nodejs

背景

Ubuntu 18.04 上 apt 能安装的 nodejs 版本是 10.19.0，而官方早就更新到了 18.x，所以会有一些新的 module 不兼容。

安装方法

安装

根据官方 docs 的方法，需要增加 nodejs 的 repo 源

1
2

curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt install nodejs

安装完成后查看版本号

配置

  1. 建立 npm 包安装及缓存文件夹（如果建在/usr/local 目录下，后面运行安装的包会有权限问题）

    1
2

    mkdir -p ~/.npm/node_global
mkdir -p ~/.npm/node_cache

  2. 配置 npm

    1
2

    npm config set prefix "/home/jason/.npm/node_global"
npm config set cache "/home/jason/.npm/node_cache"

  3. 因为 npm 在国内比较慢，所以可以安装 cnpm，之后安装其他包可以使用 cnpm install -g

    1

    npm install cnpm -g --registry=https://registry.npm.taobao.org

    安装完成后建立 cnpm 的软链接

    1

    sudo ln -s /home/jason/.npm/node_global/lib/node_modules/cnpm/bin/* /usr/bin/

  4. 配置环境变量

    1
2
3
4
5
6
7

    vim ~/.bashrc

# 增加 nodejs 的环境变量
export NODE_PATH=/home/jason/.npm/node_global/bin
export PATH=$PATH:$NODE_PATH

source ~/.bashrc
