前言

好久没写博客了，最近准备重新开始，所以先来折腾一下博客框架。现在用的是 Halo，虽然功能很丰富，但是绝大部分的功能我都没有用到，而且相对静态博客来说比较重，所以经过一番比较，选择了热度比较高的 Hugo 作为新的起点。

因为我比较喜欢用 Docker 容器来构建各种环境，可以避免在本地电脑上增加各种配置，也方便迁移，所以下文的所有内容都将基于容器环境。

初始化

Hugo 版本

如下是 Hugo 官方的说明，因为下面用到的主题需要拓展版 Hugo，所以博主选择的也是拓展版，也是官方推荐的版本。

Hugo有两个版本：标准版和扩展版。使用扩展版，您可以：

  • 在处理图像时，将图像编码为WebP格式。无论您使用哪个版本，都可以解码WebP图像。
  • 使用内置的LibSass转译器，将Sass转译为CSS。使用Dart Sass转译器时不需要扩展版。

我们建议您安装扩展版。

步骤

依赖的 docker-compose 文件如下，为了避免太折腾，所以我选择了环境最全的镜像标签 exts，所有的镜像标签可以在 这里 查看，也有对应的说明。

如果完全从头开始构建，那这里需要按如下步骤执行：

  1. 初始化 Hugo 项目；
点击查看 docker-compose 配置
``` yaml
services:
  hugo:
    image: hugomods/hugo:exts
    container_name: hugo
    hostname: hugo
    # restart: unless-stopped
    # command: server -D
    restart: no
    command: new site /src --format yaml # format支持json yaml toml
    ports:
      - "1313:1313"
    volumes:
      - "/mnt/user/appdata/hugo/progressio:/src"  # progressio是项目目录，/src是Hugo默认工作目录
      - "/mnt/user/appdata/hugo/cache:/tmp/hugo_cache"
    networks:
      - halo
    environment:
      - PUID=99
      - PGID=100
      - UMASK=000
      - TZ=Asia/Shanghai
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:1313"]
      interval: 30s
      timeout: 5s
      retries: 3
    logging:
      driver: json-file
      options:
        max-size: 100m

networks:
  halo:
    name: hugo
    driver: bridge
```

这里Hugo服务设置成不重启，因为只是想让它初始化一下，在初始化完成后，可以检查一下容器日志。
