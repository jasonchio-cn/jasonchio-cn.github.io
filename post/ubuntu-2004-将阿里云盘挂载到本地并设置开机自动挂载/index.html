背景

阿里云盘已经开启公测很久了，虽然大部分容量都不是永久的，但是依然有不可抵挡的诱惑——不限速。

Github 上已经有大神将阿里云盘转为 WebDAV 协议的文件服务器，仓库链接 在此

官方介绍

本项目实现了阿里云盘的 webda v协议，只需要简单的配置一下，就可以让阿里云盘变身为 webdav 协议的文件服务器。 基于此，你可以把阿里云盘挂载为 Windows、Linux、Mac 系统的磁盘，可以通过 NAS 系统做文件管理或文件同步，更多玩法等你挖掘。

作为 Docker 容器部署

以下内容摘自项目官方教程

获取必需参数 refreshToken

  1. 先通过浏览器（建议chrome）打开 阿里云盘官网 并登录
  2. 登录成功后，按 F12 打开开发者工具，点击 应用（Application），点击本地存储空间（Local Storage），点击 Local Storage 下的 https://www.aliyundrive.com/，点击右边的 token，此时可以看到里面的数据，其中就有 refresh_token，把其值复制出来即可。格式为小写字母和数字，不要复制双引号，例子：ca6bf2175d73as2188efg81f87e55f11

启动容器

装好 Docker 后，输入一下命令部署

1
2

docker run -d --name=webdav-aliyundriver --restart=always -p 本机端口:8080  -v /etc/localtime:/etc/localtime -v /etc/aliyun-driver/:/etc/aliyun-driver/ -e TZ="Asia/Shanghai" -e ALIYUNDRIVE_REFRESH_TOKEN="your refreshToken" -e ALIYUNDRIVE_AUTH_PASSWORD="admin" -e JAVA_OPTS="-Xmx1g" zx5253/webdav-aliyundriver

# /etc/aliyun-driver/ 挂载卷自动维护了最新的 refreshToken，建议挂载
# ALIYUNDRIVE_AUTH_PASSWORD 是 admin 账户的密码，建议修改
# JAVA_OPTS 可修改最大内存占用，比如 -e JAVA_OPTS="-Xmx512m" 表示最大内存限制为 512m

--aliyundrive.refresh-token
    阿里云盘的 refreshToken
--server.port
    非必填，服务器端口号，默认为8080
--aliyundrive.auth.enable=true
    是否开启WebDav账户验证，默认开启
--aliyundrive.auth.user-name=admin
    WebDav账户，默认admin
--aliyundrive.auth.password=admin
    WebDav密码，默认admin
--aliyundrive.work-dir=/etc/aliyun-driver/
    token挂载路径（如果多开的话，需修改此配置）

开机自动挂载

前期准备

  1. 安装所需软件

    1

    sudo apt-get install davfs2 -y

  2. 创建挂载目录

    1

    mkdir /home/ubuntu/alicloud

  3. 挂载阿里云盘到本地

    1

    sudo mount -t davfs -o noexec localhost:端口/文件夹名 /home/ubuntu/alicloud

    端口就是刚刚启动容器时设置的本地端口，文件夹名就是要挂载到本地的阿里云盘的文件夹名，不设置文件夹就是默认所有文件夹。

  4. 按要求输入账户和密码，挂载成功后，即可当正常磁盘一样访问 WebDAV 服务了，速度快慢取决于网速。

  5. 输入 df -h 即可看到是否挂载成功

  6. 解除挂载

    1

    sudo umount /home/ubuntu/alicloud

设置开机自动挂载

设置 WebDAV 免登陆密码

修改 /etc/davfs2/secrets，增加下面一行

1

localhost:端口/文件夹名 davusername davpassword

设置开机自动挂载

修改 /etc/fstab，增加下面一行

1

localhost:端口/文件夹名 /home/ubuntu/alicloud davfs rw,user,uid=username,auto 0 0

uid 就是当前 Linux 用户名，不是 WebDAV 服务的用户名。

详细的挂载格式可以参考上一篇博文 Ubuntu 20.04 开机自动挂载 NTFS 格式存储设备
