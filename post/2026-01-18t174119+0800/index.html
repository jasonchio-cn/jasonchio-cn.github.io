前言

由于博主时不时会折腾一下电脑，进而可能需要时不时（其实也没有）重装一下电脑，同时为了记录和分享一下多年以来一直在用或近期发现比较好用的软件，所以打算开启一个新系列——赛博记忆。本篇是该系列的第一篇，从准备要重装的 Windows PC 开始记录。

先列出所有通过 Scoop 安装的软件。

效率工具

PixPin

目前发现的最好用的截图软件，支持截图、贴图、长截图、Gif 录制、截图标注、截图文本识别等丰富的功能。

安装包

官网地址：PixPin - 强大且免费的截图贴图工具

Listary

Listary  拥有两大核心功能，一个是拥有  Everything  般闪电般毫秒级的全盘文件搜索功能 (支持拼音模糊搜索)；另一个是让资源管理器和文件对话框的集成增强，支持超方便的“路径跳转”+“文件快速定位”等功能。让 Windows 的资源管理器和文件查找比以前好用一万倍！（摘自异次元）

它的文件夹快速跳转功能到现在还没有替代品，非常好用的功能。在其他软件中选择文件的时候，按 Ctrl+G 就能快速跳转到已打开的文件夹中，对于选择刚下载或者打开的文件，非常便捷。

安装包

官网地址：Download Listary for Free - File Search Tool and App Launcher 相关介绍：

Scoop

1

scoop install extras/listary

PowerToys

微软官方出品的一个工具包型的软件，我常用的就是窗口置顶、窗口分区、查找我的鼠标、文件预览。

安装包

项目地址：GitHub - microsoft/PowerToys: Windows system utilities to maximize productivity

Scoop

1

scoop install extras/powertoys

PicList

PicGo 的功能更丰富版，官方介绍：

PicList 是一款高效的云存储和图床平台管理工具，基于 PicGo 深度二次开发，提供完整的图床功能和全面的云存储管理能力，主要特点包括：

  • 完整保留 PicGo 所有功能，兼容大部分 PicGo 插件
  • 扩展了内置图床平台，如 WebDav、本地图床和 SFTP 等
  • 相册支持同步云端删除文件
  • 全面的云存储管理功能，包括文件操作、搜索和预览
  • 内置图像处理工具，如水印、压缩、缩放、旋转和格式转换
